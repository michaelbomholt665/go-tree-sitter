# Manifest Schema v2 Specification

This document defines the schema, field contracts, and validation invariants for `manifest.json`, generated by [`GenerateManifest`](file:///home/michael/projects/go/tree-sitter/internal/tree-sitter/build/manifest.go#L56) and verified by [`ValidateManifest`](file:///home/michael/projects/go/tree-sitter/internal/tree-sitter/build/manifest.go#L135).

---

## 1. Overview & Rationale

`manifest.json` is a **custom manifest format** designed specifically for this repository. It was created to give downstream applications (such as the author's **graph builder**) an easy, programmatic way to inspect, control, and verify grammar versions, target platform/architecture binaries, SHA-256 checksums, and concrete runtime ABI versions without manual guesswork or runtime symbol crashes.

Schema v2 separates a parser binary's concrete, measured ABI from the runtime parser's supported ABI compatibility range:

In Schema v1:
- `abi.min_version` and `abi.max_version` were recorded as an arbitrary range from external configuration tables.
- `parser_version` could be populated from upstream npm package versions.
- Binary files were not verified against live symbols.

In Schema v2:
- `parser_abi` records the **exact measured ABI** returned by `Language.AbiVersion()` from the final native binary.
- `tree_sitter_version` records the **exact version** parsed from the invoked `tree-sitter --version` CLI tool.
- Full compilation provenance is tracked per binary in `build_provenance`.
- Runtime compatibility range is left to the consumer's linked Go binding (`sitter.MIN_COMPATIBLE_LANGUAGE_VERSION` and `sitter.LANGUAGE_VERSION`).

## 3. Field Specifications

### Top-Level Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `schema_version` | integer | Must be strictly `2`. |
| `grammar` | string | Grammar constructor suffix (e.g. `c`, `c_sharp`, `python`). Constructor function is strictly `tree_sitter_<grammar>`. |
| `version` | string | Pinned upstream version label. |
| `compiled_at` | string | ISO 8601 UTC timestamp (`time.RFC3339`) derived deterministically from the source git commit timestamp. |
| `tree_sitter_version` | string | Version string parsed from the invoked `tree-sitter --version` tool. |
| `parser_abi` | integer | Concrete parser ABI version measured directly from the native binary. |
| `binaries` | list[object] | Sorted list of compiled binary descriptors. |
| `abi` | object | Backward compatibility structure for v1 consumers. |
| `artifacts` | object | Artifact availability flags (`has_node_types`, `has_compact_node_types`, `has_queries`, `has_wasm`, `has_c_source`, `has_js`). |
| `build_provenance` | list[object] | Detailed compiler and toolchain provenance per binary. |

---

### `binaries[]` Object Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `platform` | string | Operating system platform: `"linux"`, `"windows"`, or `"macos"`. |
| `arch` | string | Target architecture: `"amd64"` or `"arm64"`. |
| `filename` | string | File name of the published shared library. |
| `checksum_sha256` | string | Lowercase hexadecimal SHA-256 hash of the final published binary file. |

---

### `abi` Object Fields (Compatibility)

| Field | Type | Description |
| :--- | :--- | :--- |
| `min_version` | integer | Set equal to `parser_abi`. |
| `max_version` | integer | Set equal to `parser_abi`. |
| `parser_version`| string | Set equal to `tree_sitter_version`. |

---

### `artifacts` Object Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `has_node_types` | boolean | Indicates whether `node-types.json` is published alongside grammar artifacts. |
| `has_compact_node_types` | boolean | Indicates whether token-efficient AST representation `compact-node-types.yaml` is generated and published. |
| `has_queries` | boolean | Indicates whether `.scm` query definitions are published in `queries/`. |
| `has_wasm` | boolean | Indicates whether WebAssembly binary `tree-sitter-<lang>.wasm` is compiled and published. |
| `has_c_source` | boolean | Indicates whether C/C++ parser sources are preserved under `src/`. |
| `has_js` | boolean | Indicates whether the grammar specification `grammar.js` is preserved. |

---

### `build_provenance[]` Object Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `filename` | string | Filename matching the corresponding entry in `binaries`. |
| `source_repository`| string | Git repository URL from which grammar was cloned. |
| `source_revision` | string | 40-character hexadecimal commit SHA checked out. |
| `generator_version`| string | Exact `tree-sitter` CLI version used during generation. |
| `generate_abi` | integer | ABI version passed to `tree-sitter generate --abi`. |
| `source_date_epoch`| integer | Unix timestamp (seconds since epoch) of the git commit. |
| `node_types_sha256`| string | SHA-256 checksum of the generated `node-types.json`. |
| `target_triple` | string | Compiler target triple (e.g. `x86_64-linux-gnu`). |
| `compiler` | string | Resolved C compiler executable name. |
| `compiler_version` | string | Full first line emitted by `<compiler> --version`. |
| `build_flags` | list[string] | C/C++ compiler flags applied during the build. |

## 4. Validation Invariants

The [`ValidateManifest`](file:///home/michael/projects/go/tree-sitter/internal/tree-sitter/build/manifest.go#L135) function enforces the following invariants before any catalog is published:

1. **Schema Check:** `schema_version` must equal `2`.
2. **Positive Measured ABI:** `parser_abi` must be greater than `0`.
3. **Compatibility Bounds:** `abi.min_version` and `abi.max_version` must both strictly equal `parser_abi`.
4. **Version Parity:** `abi.parser_version` must strictly equal `tree_sitter_version`.
5. **Checksum Match:** The SHA-256 hash of every physical file in `data/tree-sitter/grammar/<lang>/` must match `checksum_sha256`.
6. **Provenance Match:** Every binary must have an associated provenance entry with identical generator and compiler records.
7. **ABI Uniformity:** All binaries within a single grammar must have identical measured parser ABIs.
8. **Artifact Integrity:** When `has_wasm`, `has_c_source`, `has_js`, or `has_compact_node_types` are true, their corresponding files (`tree-sitter-<lang>.wasm`, `src/parser.c`, `grammar.js`, `compact-node-types.yaml`) must be physically present in the published grammar directory.
