# Tree-sitter grammar builds

Use the installed `ts-build` command. Inspect the selected configuration and catalog before changing settings or building. Select only the requested grammars and artifacts.

- For configuration commands, keys, and defaults, read [configuration](references/configuration.md).
- For selection, generation, compilation, validation, and publication, read [build grammars](references/build-grammars.md).
- For configured grammar identifiers and pins, read [grammar catalog](references/grammar-catalog.md); use `ts-build list` for the active configuration.
